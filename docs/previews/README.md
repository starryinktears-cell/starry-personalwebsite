## 使用说明

- 这些是布局、层级、色彩和内容密度参考，不是最终可交付的像素级设计稿。
- 图片里的品牌名、示例项目和联系信息都是占位内容，开发时替换成真实数据。
- 图片文字由生成模型绘制，实际实现应以需求文档中的字段、路由和状态为准。
- 公开页面与后台页面可以分别作为 AI 的参考组，保持同一品牌但区分“展示”和“管理”两种任务。

生成方式：内置 `image_gen`，逐页生成，未使用外部图片输入。
