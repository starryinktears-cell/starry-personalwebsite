# 基础模板检查点

## 分支用途

- 模板分支：`codex/base-template`。
- 分支起点：`main` 的 `e81b724`（可编辑公开导航），加上截至本检查点的本地功能修复与后台体验改进。
- 用途：保留个人内容正式替换前可回溯的基础模板；后续个性化工作可以从这里建立新分支。
- 本次仅创建本地分支并提交，不推送、合并 main 或触发生产部署。

## 已保存的功能

1. 保留 React + TypeScript + Tailwind、Vercel Node API、Supabase Auth / 数据库 / Storage 接入，以及现有迁移、RLS、owner_id 隔离和项目发布流程。
2. 图片、视频新上传统一限制为 5 MB；前端、Node API、提示与环境变量示例一致。已有媒体继续可用。
3. 本地演示媒体改用 IndexedDB 保存文件，localStorage 保存引用；兼容旧图片，支持刷新后恢复，避免 base64 导致的本地容量问题。
4. 站点设置保留品牌共用字段，按首页、关于、服务、联系、全站、页脚组织二级子标签；桌面右侧显示当前区块未保存预览，切换模块保留草稿。
5. 桌面后台左侧私密工作区固定在视口，过长导航可在侧栏内滚动；右侧编辑区域正常滚动。
6. 六组莫兰迪配色、自定义主色与独立页脚背景、原始墨绿重置、头图自动取色；保存后全站生效。取色失败保留原色，手动选色不会被过期异步结果覆盖。
7. 联系页标题、简介、城市、坐标、时区文字与全站时钟 UTC 时差均有后台编辑入口；站点默认所在地为深圳。
8. 作品详情取消滚动停留后自动导航，仅通过前后项目链接切换；保留图片灯箱、媒体操作、双语和已有后台入口。
9. 主题扩展保存在既有 `site_settings.seo.theme`，扩展文案使用 `seo.content`，本次无需新增数据库迁移。

## 数据边界

- Git 分支保存代码、依赖锁定文件、迁移和文档，不备份浏览器 localStorage / IndexedDB 或 Supabase 数据。
- 本地后台中保存的品牌、文案和上传图片仍在原浏览器同一来源中；`localhost` 与 `127.0.0.1` 的演示数据彼此独立。
- 生产数据库、Auth 用户与 Storage 媒体仍保存在原 Supabase 项目；切换 Git 分支不会迁移或回滚这些数据。
- 用户提供的个人简历与作品集本轮仅用于只读分析，没有写入模板。个性化文案、真实案例和联系方式尚未按简历替换。
- 不包含真实密钥、浏览器存储导出、个人 PDF、生产媒体或验证截图。`.env.example` 仅保留占位值，`.env.*`、`.vercel`、`.goal`、构建输出和依赖目录保持忽略。

## 使用方式

在工作区干净时，从该模板建立新的个性化开发分支：

```bash
git switch -c codex/personal-content codex/base-template
npm ci
npm run dev
```

本地无 Supabase 环境变量时使用演示模式。真实环境配置、迁移、测试和部署步骤参见根目录 `README.md`。不要用模板中的默认内容覆盖已有生产数据。
